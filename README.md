# South African Businesses & Jobs Dashboard

An interactive, responsive dashboard that explores estimated business numbers and employment distribution across South Africa from **2018 to 2025**.

## 1. Project Overview

The South African Businesses & Jobs Dashboard provides a visual representation of business activity and employment across different business size categories.

The dashboard allows users to explore business and employment trends, compare different business categories, and examine how estimated business numbers and employment figures change over time.

## 2. Dashboard Features

The dashboard includes the following features:

- **Business Count Analysis:** Explore estimated business counts across different employee-size categories.
- **Employment Distribution:** Examine employment distribution across businesses of different sizes.
- **Year Filtering:** Filter the dashboard data by year.
- **Business Size Filtering:** Select specific business size categories to explore.
- **Interactive Line Chart:** View changes and trends in estimated business numbers over time.
- **Business Comparison:** Compare estimated business counts across different business size categories using bar charts.
- **Employment Comparison:** Compare employment figures across different business size categories.
- **Responsive Design:** Access the dashboard through different screen sizes and devices.

## 3. Business Size Categories

The dashboard uses the following business size classifications:

| Category | Number of Employees |
|---|---|
| Micro | 0–9 |
| Small | 10–49 |
| Medium | 50–249 |
| Large | 250–999 |
| Very Large | 1,000+ |

## 4. Technologies Used

The project was developed using the following technologies:

- **HTML5:** Provides the structure and layout of the dashboard.
- **CSS3:** Handles the dashboard styling, visual appearance and responsive layout.
- **JavaScript:** Implements the dashboard functionality, data processing, filtering and interactivity.
- **Chart.js:** Used to create interactive data visualisations and charts.
- **CSV:** Used to store and organise the business and employment dataset.

## 5. Data Source

The dashboard uses business and employment data obtained from **Statistics South Africa (Stats SA)** through the SEAD-SA data source.

The dataset covers the period from **2018 to 2025** and provides estimated business and employment information across different business size categories.

## 6. File descriptions

- `index.html` – Contains the main structure of the dashboard.
- `style.css` – Contains the styling and layout of the dashboard.
- `script.js` – Handles data processing, filtering and chart functionality.
- `data/` – Contains the datasets used by the dashboard.
- `README.md` – Provides information about the project.

## 7. How to Run the Dashboard

1. Download or clone the project repository from GitHub.
2. Extract the project folder if it was downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Ensure that the dataset files are located in the correct `data/` folder.
5. Open `index.html` using a web browser, or run it using the Live Server extension in Visual Studio Code.

## 8. Project Purpose

GMT 320 (UP) assignment 2: 

The purpose of this project is to make South African business and employment data easier to explore and understand through interactive data visualisation.

By presenting the information through charts, comparisons and filtering tools, the dashboard helps users identify patterns, examine differences between business size categories and explore changes in estimated business activity over time.
